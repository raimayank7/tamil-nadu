How the code UTIB0003696 is built

UTIB is the bank part: the letters of Axis Bank. The fifth character is always the digit 0. 003696 is the part that names this branch.

The MICR code 609211202 is the number printed along the bottom of this branch's cheques. 609 is the city (the same three digits that begin the PIN code 609110), 211 is the bank and 202 is the branch.
