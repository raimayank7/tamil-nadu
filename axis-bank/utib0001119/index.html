How the code UTIB0001119 is built

UTIB is the bank part: the letters of Axis Bank. The fifth character is always the digit 0. 001119 is the part that names this branch.

The MICR code 600211033 is the number printed along the bottom of this branch's cheques. 600 is the city (the same three digits that begin the PIN code 600100), 211 is the bank and 033 is the branch.
