How the code BARB0KULASE is built

BARB is the bank part: the letters of Bank of Baroda. The fifth character is always the digit 0. KULASE is the part that names this branch.

The MICR code 629012103 is the number printed along the bottom of this branch's cheques. 629 is the city (the same three digits that begin the PIN code 629161), 012 is the bank and 103 is the branch.
