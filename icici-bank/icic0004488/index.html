How the code ICIC0004488 is built

ICIC is the bank part: the letters of ICICI Bank. The fifth character is always the digit 0. 004488 is the part that names this branch.

The MICR code 600229164 is the number printed along the bottom of this branch's cheques. 600 is the city (the same three digits that begin the PIN code 600020), 229 is the bank and 164 is the branch.
