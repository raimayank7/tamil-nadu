How the code TMBL0000251 is built

TMBL is the bank part: the letters of Tamilnad Mercantile Bank. The fifth character is always the digit 0. 000251 is the part that names this branch.

The MICR code 632060103 is the number printed along the bottom of this branch's cheques. 632 is the city (the same three digits that begin the PIN code 632503), 060 is the bank and 103 is the branch.
